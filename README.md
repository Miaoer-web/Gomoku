# 爪爪落子

Windows x64 双人桌面游戏。15×15 棋盘，黑棋先下，横、竖或斜线恰好五连获胜，六连及以上不算该方向获胜，双方无禁手。

右侧最下方的「软件主题」可切换深色和浅色。两套主题的布局相同。棋盘可单独选择石墨灰、经典木色、胡桃木、深海蓝、墨玉绿或暮紫。软件主题和棋盘设置只影响自己的窗口。

棋盘上方显示房间、对局和观战人数。右侧依次是「房间」「席位」「对局」「外观」「软件主题」。窗口较矮时可上下滚动右栏。

- 「棋盘」的「选择图片」可选本机图片作背景。「重置」恢复石墨灰。棋盘设置只在当前窗口显示。
- 可在「棋子」选择经典、小猫、小狗、橘子、苹果、汉堡、吉伊、小八或乌萨奇。造型棋子的角标区分黑白方。「选择图片」会将本机图片居中裁切并铺满圆形棋面，「重置」恢复经典。未进房时只预览自己选的一颗棋子。进房后，两人各自选择自己执色的棋子皮肤，双方窗口同步显示，重开时保留。
- 双方窗口用橙色细环标记全局最后一颗落子。重开时清除标记。

## 先在一台电脑上试玩

1. 解压整个压缩包，保留 Play 里的目录和配套文件。
2. 双击两次 `Play\Desktop\爪爪落子.exe`。
3. 第一个窗口点「创建」，游戏会在后台启动房间服务。第二个窗口填 `127.0.0.1` 和四位房间号，再点「加入」。
4. 好友加入后，房主点「开始」。黑棋先下，点击棋盘交叉点落子。对局中任意一方可点「认输」，另一方获胜。任意一方点「重新开局」即可清空棋盘并开始下一局。

房间可容纳黑棋、白棋和观战各一人。「席位」会标出你的身份，点空席可切换。对局中缺少一方时暂停，席位补齐后继续。开局前或本局结束后，黑白双方都可切换换色模式。默认「轮换模式」每次重开自动交换黑白。「互换模式」下双方都可点「互换黑白」。棋盘中央的结算卡显示「你赢啦~」或「你输啦~」，关闭后可继续查看棋局。

发布包包含免安装 EXE。运行游戏需要 .NET 10 Desktop Runtime（x64），运行房间服务的电脑还需要 ASP.NET Core Runtime 10（x64）。已经安装这些运行环境时，直接运行即可。

## 和朋友联机

两台电脑连同一个局域网。双方只需打开游戏。房主点「创建」后，把游戏显示的主机 IP 和四位房间号发给好友。好友填入后点「加入」。

升级时，先关闭旧游戏和旧版房间服务窗口，再从新版压缩包解压并启动。

- **同一个 Wi-Fi**。好友直接填写游戏显示的主机 IP，例如 `192.168.1.20`。如果房主有多个网卡，可用 `ipconfig` 核对 Wi-Fi 的 IPv4 地址。
- **住在不同地方**。两台电脑加入同一个私有虚拟局域网。朋友填写主机的虚拟局域网 IP 和四位房间号。
- 连接不上时，先确认房主已创建房间、双方在同一个局域网且 IP 正确。Windows 防火墙首次询问时，可允许房间服务在专用网络中通信。也可检查 TCP 5080 是否允许在该私有网络上访问。

好友点「退出」会腾出席位。房主点「退出」或关掉游戏会关闭房间和后台服务。房间状态保存在主机内存，下次游玩需要重新建房。

## 从源码重新打包

在安装了 .NET 10 SDK 的 Windows x64 电脑上，打开 PowerShell，进入本 README 所在目录：

```powershell
dotnet publish .\Desktop\Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\Package\Desktop
dotnet publish .\Server\Server.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\Package\Server
```

首次生成自带运行环境的版本需要联网下载 .NET 运行时包。发布成功后，压缩并分享整个 Package 文件夹，保留同级的 Desktop 和 Server 目录。双方都只打开 Desktop 里的程序。
